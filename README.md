# HSBC Banking Customer & Transaction Analysis

## Project Overview

This project analyzes customer demographics, banking products, account types, and transaction patterns using SQL and Excel. The objective is to identify meaningful customer insights and support data-driven banking decisions.

## Business Problem

Banks need to understand customer behavior, transaction activity, and account usage to improve customer retention, customer segmentation, and banking service decisions.

## Tools & Technologies

* SQL (MySQL)
* Microsoft Excel
* Data Cleaning
* Data Analysis
* Dashboard Development

## Key Analysis Areas

* Customer segmentation by age, city, and employment type
* Account type and banking product analysis
* Transaction amount and transaction count analysis
* Credit score and annual income analysis
* Transaction channel performance
* Customer status and activity analysis

## Key Business Applications

* Identify customer segments with different banking needs.
* Understand transaction behavior across banking channels.
* Support customer retention and personalized product recommendations.
* Help banking teams make data-driven service and marketing decisions.

## Project Files

* `SQL_Queries/` — SQL analysis queries
* `Dashboard/` — Excel dashboard and report
* `Dataset/` — Dataset, if permitted for public sharing

## Disclaimer

This is a portfolio project created for educational and analytical purposes using a sample banking dataset. It does not represent actual HSBC internal data or official HSBC business analysis.
